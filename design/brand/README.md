# Connected P — logo concept

Concept 01: a review-stage identity for Pentelligence, retained as a starting point for further refinement. Not integrated into the application or approved as the final brand.

The P follows a continuous investigation path with three enlarged connection points. The angular bowl keeps the silhouette distinct while the open counter remains legible at small sizes. Colours match the existing application.

## Assets

- `preview.svg`: self-contained concept board with light/dark applications and size checks.
- `connected-p.svg`: transparent lime symbol.
- `connected-p-mono.svg`: transparent charcoal symbol for light backgrounds.
- `connected-p-white.svg`: transparent white symbol for dark backgrounds.
- `wordmark.svg`: lime symbol and off-white live-text wordmark for dark backgrounds.

Use charcoal on light backgrounds; lime is intended for dark backgrounds. Leave at least one node diameter of clear space around the mark. The 16px rendering is a review specimen; consider an optically simplified favicon before release.

The wordmark uses Space Grotesk when installed, with Arial fallback. It is not an outlined production wordmark: final typography and outlined export should follow concept approval. The preview board uses Arial for portable review. The ASCII terminal treatment `[P>] pentelligence` is a proposed text companion, not a replacement for accessible command output.

No trademark or similarity clearance has been performed. Review suitability before public adoption. No app icons, favicon, or existing branding have been replaced.
